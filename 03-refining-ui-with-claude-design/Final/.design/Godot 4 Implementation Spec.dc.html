Note on gradients
The design uses linear/radial gradients throughout. Godot's StyleBoxFlat supports only solid fills. Each gradient entry below lists both a flat fill (safe midpoint approximation) and the full gradient description. For fidelity, use a ShaderMaterial or a GradientTexture2D applied to a TextureRect.

Emoji rendering in Godot
Emoji are used extensively (📖 🧺 🌕 🕷️🍯 etc.). Godot's default font does not render color emoji. Options: (a) import a Noto Color Emoji .ttf and add it as a fallback in your FontFile; or (b) replace each emoji with an exported PNG sprite (TextureRect) — recommended for production.

Section 6

Anchoring & Resize Behavior

Scaling Strategy

The design is authored at a fixed 1920 × 1080 canvas. The recommended Godot approach is to set the project's display/window/stretch/mode to canvas_items and aspect to keep. This uniformly scales all Control nodes and preserves pixel values exactly as specified. Set the base window size to 1920 × 1080. Letterboxing/pillarboxing handles non-16:9 displays with the bg_deepest color filling the bars.
